Step 1 — Get an access token from Hydra

Your backend calls Hydra's token endpoint with your credentials and gets back a signed JWT. You then attach this token to every call you make to the Identity API.

Space-separated. Only your approved scopes will be granted by Hydra.
POST http://localhost:4444/oauth2/token
Content-Type: application/x-www-form-urlencoded

grant_type=client_credentials
&client_id=...
&client_secret=[your secret]
&scope=...

What happens behind the scenes

        
    
          
  1. Your backend sends its client ID and secret to Hydra (OAuth2 server) and receives a signed access token.
    2. 
          
  2. You include that token in the Authorization header when calling the NatID Identity API.
    3. 
          
  3. The API contacts Hydra to verify the token is genuine and not expired (token introspection).
    4. 
          
  4. The API reads which scopes are in the token and filters the user's data accordingly.
    5. 
          
  5. Every request is logged — admin can see every access your company made.
